# Mis gastos — descargas

Instaladores de **Mis gastos** para Windows. Descarga el más reciente en [Releases](../../releases/latest).

La app instalada revisa aquí si hay una versión nueva y se actualiza sola. Cada instalador va firmado y la app solo acepta los firmados por su autor.

Este repositorio solo tiene los instaladores: no tiene el código de la app ni datos de nadie.
